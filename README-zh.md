# dsh-lobsterai-daddy

> LobsterAI 账号抽屉：转接端口状态、定时自动签到、积分总览与一键打开控制台。

> 完整文档以 [English README](./README.md) 为准，本页提供中文导读与关键信息速查。

## 效果图

面板自上而下是：操作按钮区 → 当前登录账号 → 账号列表（余额 / 套餐 / 今日已用 / 奖励明细 / 签到状态 / token 到期）。顶部圆点变绿表示 LobsterAI 正在运行；右侧「内置 · 账号 N 个」表示数据由插件宿主直读，不依赖任何外部控制台进程。完整截图见 [English README](./README.md)。

## 功能

免退出并行登录任意多个账号；一键切换当前账号；定时自动签到（默认每 60 分钟一轮）；积分与套餐实时查询；转接端口状态显示；一键打开网页控制台。

## 安装

在插件市场搜索 `dsh-lobsterai-daddy` 安装，或执行 `dsh plugin add dsh-lobsterai-daddy`。装好后重启 DSH，桌面右下角会出现悬浮球。

## 原理

宿主半边直接读取 LobsterDaddy 的本地凭据与控制台数据（不需要外部进程介入），再通过回环路由把数据交给客户端半边渲染成原生 DOM 悬浮球与抽屉——全程不用 iframe。

## 配置

在 `cordis.yml` 的插件 config 段可调悬浮球初始位置、面板跟随行为、签到周期等；不配置也能跑，全部有默认值。

## 兼容性

需要 DSH 0.2 世代（`dsh.bundle` 插件体系）；宿主端需要 Node 22.19+ 或 24+。

## 常见问题排查

① 悬浮球不出现：确认插件已启用且 DSH 重启过；② 端口未读取：说明当前 provider 不是 lobsterai（本插件只在 lobsterai 为活动 provider 时能探测到转接端口）；③ 签到没执行：检查 LobsterDaddy 是否在运行、账号是否已登录。

## 安全说明

插件只读取本机 LobsterAI 的凭据与控制台数据，全部走回环地址（127.0.0.1），不向外部服务器发送任何账号信息。
